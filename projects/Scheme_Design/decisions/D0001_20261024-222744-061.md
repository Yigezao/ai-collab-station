# 第1轮裁决：采纳 S02 的 11 处硬伤修订与 D1–D8 定案，冻结 5 个基线数字

# 第 1 轮讨论裁决（D1–D8 / F1–F11 / G1–G7）

> 裁决人：MGR。依据：S01 提案 `R0001_S01_20261024-222352-896.md`、S02 评审 `R0001_S02_20261024-222601-240.md`。
> 裁决原则：可验证 > 好看；数字必须自洽；不把推定写成实测；模板要对“用户自己的 AI”可执行。

## 一、硬伤（F1–F11）：全部按 S02 版本改

- **F1 字数与时长互斥**：取消区间制，改单点目标 ±8%；时长以 TTS 实测 ±1.0 分钟为准，两者冲突时以实测为准。
- **F2 防幻觉位置错了**：把素材卡改为**输入闸门**——`author_bio / ending / key_settings / quotes` 任一为空，模板必须拒绝进入 SCRIPT 阶段，只输出“缺哪些素材”。FACT_CHECK 降级为复核清单。
- **F3 输出标记**：V1 正文**零标记**，不允许 `[停]`/`【重音】` 混入正文；停顿靠句号、分段和短句。
- **F4 字数校验不可复现**：字数只自报并标“估算”，判定权交 TTS 实测；切句口径写死为“按 。？！… 切句，只数汉字，不含标点、数字、引号内文字”。
- **F5 节拍与槽位冲突**：节拍规则只在 S3/S4 生效（每 90–150 秒一个新信息或转折）；S5 不设小结，改为 2–3 个递进问题；删“90–120 秒小高潮”，与“6–8 个情节点（每个 70–110 秒）”统一。
- **F6 语速**：只保留单一 `cpm` 字段；270 的说法作废，不得再出现“实测口径”字样。
- **F7 S6 字数**：S6 固定 30 秒，字数按容量给足（见方案冻结表）。
- **F8 禁用词/句长**：禁用表拆两模式各 6–8 条；句长改为“平均 16–26 字，单句 >30 报错，≥40 只提示”。
- **F9 质检覆盖**：QC 拆 `AI_SELF_CHECK`（6 项机器可判，必须附命中原文）+ `HUMAN_CHECK`（5 项人工）。
- **F10 未定义引用**：钩子 8 型必须在 02 内定义，并规定“连续 3 期不用同一型”。
- **F11 未验证数据**：所有时间/成本数字标“预计”，并附流水线时间表。

## 三、补漏（G1–G7）：全部采纳

- **G1**：输出加第 5 块 `PUBLISH`——标题 3 候选（≤20 字，含书名 + 钩子词）、封面大字 1 行（≤10 字，与标题不同角度）、简介 80–120 字、标签 5 个。
- **G2**：账号标识（3–8 字）固定放 S2 开头第 8–15 秒，每期一字不改；钩子仍不自我介绍；S6 只留签名 + 1 个互动问题 + 1 句预告。
- **G3**：06 选题与排期——30 本池 + 三列状态（书/类型/素材状态）+ 素材来源；硬规则“没读透、没素材的书不讲”。
- **G4**：TTS 朗读适配规范写进 02（生僻字、他/她/它换名字、数字读法、英文缩写中文化、符号清零、单段 ≤200 字、多音字清单）。
- **G5**：版权边界写进 01 与 06（书名作者名可用；单处引文 ≤50 字、全文 ≤300 字、标出处；封面不用原书封面/剧照；连载中作品不做逐章复述；平台要求时标 AI 生成）。
- **G6**：执行协议写进 02——第 0 轮只输出 MODE + 参数表 + OUTLINE 等“继续”；每次只写 1–2 段并自报字数；QC 另起一条消息；固定续写句式；模板自包含，不依赖模型对本书的记忆。
- **G7**：“讲明白”验收测试——S2 必须给出“谁—想要什么—被什么挡住”一句话；文学类 3 个问题必须是对立选择题（A 还是 B）。

## 四、进方案前冻结的 5 个数

1. **默认时长**：15 分钟；10 / 20 为缩放档。
2. **字数目标**（单点，±8%）：文学 2500 / 3750 / 5000；叙事 2900 / 4350 / 5800。
3. **cpm**：文学 250、叙事 290（推定值，首 3 期实测覆盖）。
4. **S5 占比**：≤23%。
5. **【待核】位置**：只允许出现在 S3/S4；S1 钩子与 S5 结论禁止；发布前人工清零。

## 五、留待 V1.1 / V2

- 模板拆分为 02a/02b（仅当实测串模率高）。
- 真实 TTS 校准数据（需用户前 3 期实测，V1 只给方法与字段）。
- 字幕、配图、多图视频（V2）。

## 六、结论

骨架（6 槽位 + 字数反推 + 双模式模块包）保留，不需要推翻；按上述修订直接进方案 v1，提交用户批准。
