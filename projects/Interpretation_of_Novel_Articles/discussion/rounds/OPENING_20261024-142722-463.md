# 总管开场

用户追加需求（要点）：再出一版 UI 简化方案 v3。要求：不要任何专业术语，不要一大堆解释词，目标是完全不懂的小白也能上手。界面按「第1步…第2步…」这种简单分步描述；参数也用中文说清楚效果，例如勾选这个会怎样。本轮只产出 v3 UI 设计方案，不落地实施。

请每人交一份尽量短的建议，回答四件事：
1) 页面分几步、每步用户看到什么/点什么/拿到什么（用大白话，不用术语）。
2) 每步出现的选项和参数，给出中文名 + 一句「勾了有什么用 / 不勾会怎样」。
3) 现有界面里哪些词是术语，v3 换成什么中文说法（给对照表）。
4) 小白最容易卡住的地方，v3 用什么设计消掉它。

不写代码、不改文件、不做实施，只出设计文字。
