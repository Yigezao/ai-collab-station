# v3 小白版 UI 设计建议（S01）

一句话定位：把 v2 的五个技术步骤改成“五张大卡片、一屏一步、页面上不出现英文和文件名”，所有术语换成大白话，技术项全部收进“更多设置”。

## 1) 页面分几步、每步看到什么/点什么/拿到什么

页面结构：顶部一条进度条（第1步…第5步，做完变绿），下面一页放五张卡片，**只展开你现在该做的那一张**，其余折叠成一行。每张卡片只有三样：一句“这一步做什么”、一个选/填的地方、一个大按钮。

第 1 步 · 找来一本书
- 看到：三个大按钮：① 用我电脑里的文件 ② 网上找免费老书 ③ 用上次导入过的。
- 点：①弹出选文件（可一次选多个），文件名列出来，点“导入”；②输入书名，点“搜一下”，结果每行一个“下载这本”。
- 拿到：一张书卡（书名、作者、来自哪个文件），写“已准备好，可以进入第 2 步”。一次导入多个文件时只问一句“用哪一本？”，不再出现版本、绑定、解析。

第 2 步 · 把书切成小段
- 看到：第 1 步的书卡自动带过来，显示“已选好：《XXX》”；一个输入框“每段大约多少字”，下面实时一句“大概 3 分半一段”。
- 点：大按钮“开始切分”。
- 拿到：分段列表（第1段《章节名》820字…），底部写“已切好 N 段，可以进入第 3 步”。

第 3 步 · 写解说稿
- 看到：N 段列表带勾选框，顶部两个选项（见参数表）。
- 点：“写全部”或“只写勾选的”。
- 拿到：每段后面出现“已写好 · 查看”，点开能读；失败的段变红并给“再试一次”。

第 4 步 · 配上录音（这一步要你自己录音）
- 看到：一句大提示“工具不会帮你配音，请先自己录好”；下面是 N 段列表，每段右边一个“选音频文件”。
- 点：逐段选文件。
- 拿到：每段显示“已配好 · 时长 2:31”，没配的标红；全配好后“可以进入第 5 步”。

第 5 步 · 做成视频
- 看到：两个大按钮“用视频画面”“用图片”；下面一个“声音和画面不一样长怎么办”（4 个中文选项）。
- 点：“开始合成”。
- 拿到：“打开视频”按钮 + “打开所在文件夹”。

## 2) 每个选项的中文说法（勾了有什么用 / 不勾会怎样）

第 2 步
- 每段大约多少字（填 1000）：每段大概讲 3 分钟；填大=段少、每段长；填小=段多、每段短。
- 零头也算一段：勾了剩下的半章单独成一段（多一段）；不勾并到下一段（默认，不丢字）。
- 覆盖上次的结果：勾了重做并替换；不勾碰到已有结果会停下来问你。

第 3 步
- 谁来写：①“用 AI 写（会花钱，按段计费）” ②“先试写（不联网、不花钱，文字是样例）”。选 AI 时页面先提示“大约 X 元”；选试写只生成占位文字，用来先看流程。
- 重写已经写好的段：勾了把勾选的段再写一遍（再花一次钱）；不勾写过的跳过，只写没写的。
- 每次最多写多少段（填 20）：到数就停，已写的保留；填大=一次跑完但花钱多。
- 查重提醒（填 0.5，不用懂）：只提示“这段可能太像原著”，不是法律判断；填大=提示少，填小=提示多。

第 4 步
- 只允许用这个文件夹里的音频：勾了音频必须都在你选的文件夹里，防止选错；不勾可以随便选。
- 覆盖上次的结果：勾了替换上次的绑定结果；不勾碰到已有结果会停下来问。

第 5 步
- 声音和画面不一样长怎么办：剪画面让画面跟着声音结束（推荐）/ 剪声音让声音跟着画面结束 / 补一段静音把短的补长 / 我自己定（填从第几秒到第几秒）。
- 画面方向：竖屏（手机、抖音，默认）/ 横屏（电脑、B站）。
- 输出到：默认自动建文件夹；已有同名结果会拒绝，不覆盖。

其余参数（分辨率数字、帧率、ffmpeg 路径、库位置）一律不出现在主界面，收进“更多设置”。

## 3) 术语对照表（v2 现在写的 → v3 改成）

| v2 现在写的 | v3 改成 |
|---|---|
| 来源导入 / variant / manifest.json | 找来一本书 / 这本书的文件 / 书的信息 |
| work_id、variant_id、binding=inferred | 不显示；只问“用哪一本？” |
| 章节截取 / index.json | 把书切成小段 / 分段清单 |
| seg_id | 第几段 |
| 解说文案 / mock / deepseek | 写解说稿 / 先试写（不花钱）/ 用 AI 写（花钱） |
| 外部音频导入（人工节点）/ TTS | 配上录音（要你自己录） |
| 视频合成 / trim_video 等时长策略 | 做成视频 / 声音和画面不一样长怎么办 |
| preflight 本机预检 / ffmpeg / ffprobe | 开工前检查 / 播放与合成小工具（缺了给安装步骤） |
| 退出码、DEPENDENCY_MISSING、BUSY、duration_unverified | 一句话说清 + 点这里怎么办；原始内容收进“详情” |
| 库位置 / 库根目录 / --force | 保存位置 / 覆盖上次结果 |
| 分辨率 1080x1920 / fps 30 | 竖屏 / 横屏（不显示数字） |

## 4) 小白最容易卡住的地方 → v3 怎么消掉

1. 不知道从哪开始、下一步点哪：顶部常驻一条“你现在在第 2 步”，当前卡片自动展开并高亮，完成一步自动跳到下一步。
2. 怕填路径：所有路径字段改成选文件/选文件夹按钮，选完只显示文件名，路径收进“更多设置”。
3. 不知道哪些非填不可：主界面只露必填项，按钮旁灰字“还差：选一个文件”，填齐按钮才亮。
4. 看到英文错误码就懵：一律改成“出了什么事 + 点这里怎么办”两行，原始错误码折叠在“详情”。
5. 怕花钱、怕覆盖：动钱或覆盖前弹一句“这一步大约花 X 元 / 会替换上次结果，继续吗？”
6. 第 4 步不知道要自己录：卡片标题直接写“配上录音（要你自己录）”，第一条提示就是“工具不会帮你配音”。
7. 说明文字太长没人看：删掉整块常驻说明，改成字段旁一个问号点开一句话；退出码表移到页面最底“给技术同学看”。
8. 不知道做完没：每步顶部一个状态（待做 / 正在做 / 已完成），只有“已完成”才亮下一步。

## 取舍与边界
- v3 只改看得见的说法和顺序，不动流水线；第 1 步的多版本能力保留，但收成自动选择 + 一句“换一本 / 换一版”。
- 技术细节不消失，收进“更多设置”和“详情”，出问题时仍能查。
- 建议 v3 优先做四件：一页五卡、一屏一步、中文参数名、错误白话化；本对照表可直接当文案清单交给实施。
