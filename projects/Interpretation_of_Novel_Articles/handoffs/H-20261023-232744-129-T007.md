# T007 交付：模块 implemented 状态与契约口径对齐

## 目标回顾
消除 `common.constants.MODULES.implemented` 与已验收任务、`CONTRACTS.md` 口径不一致的问题，使 `status` / `/api/status` 的诊断信息可信。只改 scope 内 3 个文件，未触碰 README、各模块实现和站点目录。

## 改动
1. `common/constants.py`：`MODULES` 按任务验收状态置值——`source`（T002，S02 审查 pass E000143）、`segmentation`（T003，S04 审查 pass E000129）、`script`（T004，S02 复审 pass E000180/E000182）置 `implemented=True`；`audio`（T005）、`video`（T006）、`ui`（T004–T006）保持 `False`，注释写明解锁条件（T005/T006 done 后置 true；video 另需本机 ffmpeg/ffprobe；UI 需三步全部 done）。未改动任何枚举、错误码或契约版本。

   新增 `ACCEPTED_MODULES` / `PENDING_MODULES` 常量，后续 T005/T006 验收时只改这两处即可。
3. `common/CONTRACTS.md` §1：状态列改为显式 `implemented` 口径并写明解锁条件；补充 `implemented` 的唯一判据（交付 + 独立审查 pass + MGR 确认 done）、仅用于诊断、不参与 UI 五步状态推导；按实际 CLI 补全 audio 的 `verify` 与 ui 的 `step|chain|serve`。变更记录新增 T007 维护条，注明 `CONTRACTS_VERSION` 仍为 2。
