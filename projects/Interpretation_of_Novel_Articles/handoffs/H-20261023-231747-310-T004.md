- 来源：Project Gutenberg eBook **#24264《紅樓夢》**（Xueqin Cao / 曹雪芹，1715–1763），
  `source_id=gutenberg:24264`，目录 `language=zh`、`copyright=false`。
- 获取：2026-10-23T23:14:41+08:00 对本机网络用 `GET + Range: bytes=0-131071` 请求
  `https://www.gutenberg.org/cache/epub/24264/pg24264.txt`，HTTP 206，
  `content-range: bytes 0-131071/2663455`，`last-modified: 2026-10-10 10:29:49 GMT`。
  说明：本机对全量 GET 会在 90–120 KB 处被断开（curl exit 56；urllib `IncompleteRead(120231, 2543224 more expected)`），
  故改用官方支持的 Range 前缀；`meta.json.http.note` 如实记录。

  「第六回」标题行之前；含官方 Gutenberg 许可头、eBook 元数据与 `*** START ***` 标记，
  **不含** `*** END ***`（`meta.crop.contains_gutenberg_end_marker=false`）。
- 内容：第一回至第五回，逐字保留原文（繁体），共 110,677 字节 / 39,519 字符（含 CRLF）/ 1,248 行。
- 校验：`sha256(book.txt)=ff1dee6c19f57b4d90582d7889bfae84c22f142277dd5e16beeab7943eb53f23`；
  源前缀 131,072 字节 `sha256=02ac0cbe9b86f0b8c3438e386f5b7d6109935f9bd66d50b08b0236b23e0fe250`。
- 元数据：`meta.json` 记录 URL / eBook URL / 公版依据（作者卒年 + 目录声明 + 许可头）/ 获取时间 /
  裁剪范围 / 总文件大小 / 哈希 / 用法与限制；`provenance.json` 记录同一出处与可复现命令。
