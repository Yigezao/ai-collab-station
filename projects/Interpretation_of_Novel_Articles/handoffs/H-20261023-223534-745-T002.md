# T002 交付：P1 来源导入、Gutenberg 检索与 variant 选择

## 1. 交付内容（`source/` + `tests/source/`）

| 文件 | 职责 |
|---|---|
| `source/cli.py` | 独立入口：status / import / search / download / variants / parse / select，统一 JSON 输出与契约退出码 |
| `source/library.py` | 摄取编排、work/variant 存储、`work.json` / `comparison.json` / `selection.json`、幂等与 work 绑定确认 |
| `source/epub.py` | zipfile + OPF spine 顺序 + XHTML 文本提取，不引第三方库 |
| `source/chapters.py` | 章节识别、置信度、`chapters.json`、`chapters_override.json` |
| `source/quality.py` | 可复现质量评分（结构/洁净/完整/书名匹配 + 固定权重） |
| `source/gutenberg.py` | gutendex 多书名逐项检索、格式选择与下载、公版许可元数据 |
| `source/http.py` | TLS 固定校验、robots、限速、有限重试、结构化失败 |
| `source/README.md` | 命令用法、来源许可说明、边界与已知限制 |
| `tests/source/*` | 35 个离线测试（本地 HTTP 桩、构造 EPUB、假 Gutenberg 客户端） |

按 P0 契约 v2 适配：provenance 必填 `title/license_status/rights_basis/attribution/retrieved_at`；
本地导入 `license_status=user-provided`，Gutenberg `catalog_declared`（不写成 verified、不承诺不侵权）。

## 2. 对照 T002 验收标准

1. **多书名逐项检索**：`search "红楼梦 西游记"` 对每个书名各发一次独立请求，结果按 query 分组；测试断言 2 次请求且顺序、编码正确。
2. **同一 work 多来源 → 独立 variant 且不拼接正文**：三个本地文件同 `--title` 生成 3 个 variant，各自 `normalized/book.txt`；测试断言互不相同且不含对方前缀；`variants` 输出可复现排序（同输入两次跑分数/顺序一致，降序，章数最全者第一）。
3. **比较前确认 work 绑定**：`comparison.json` 输出 `binding` 与 `binding_requires_confirmation`；`inferred` 时 `select` 不带 `--confirm-binding` 报 `WORK_BINDING_UNCONFIRMED`（退出码 5），确认后写 `selection.json` 并记录 confirmed_at；跨 work 的 variant 报 `WORK_MISMATCH`。
4. **TLS 校验开启**：`HttpClient` 不提供 verify/insecure 参数，请求固定 `verify=True`；对纯 HTTP 端口发 https 请求实测 `TLS_VERIFY_FAILED`（退出码 4）。
5. **robots/访问拒绝结构化失败且不降级不重试**：robots Disallow 时只请求 robots.txt、不发正文请求即报 `ROBOTS_DISALLOWED`；403 只发 1 次即 `ACCESS_DENIED`；5xx/超时按 `max_attempts=2` 有限重试后 `NETWORK_ERROR`，次数写 detail。

另：`import --url` 实测返回 `WEB_SOURCE_DISABLED`、退出码 4、stdout 为 JSON；`source parse` 可重算 `chapters.json` 并同步 manifest 的 chapter_count/confidence/warnings/status。

## 4. 已知限制

1. **未做真实 Gutenberg 联网冒烟**：本轮只有离线桩测试；TLS/robots 行为用本地 HTTP 桩验证。真实站点行为需人工跑一次 `search`/`download`。
2. 下载重定向到其他主机（如 Gutenberg cache 域）时，robots 只检查初始 URL 的主机。
3. 章节识别为规则式；置信度 < 0.5 时 manifest 标 `needs_review`，`parse` 退出码 5 并提示 override。
4. `comparison.json`/`selection.json` 的 `schema_version` 沿用 1（非 manifest 契约版本）；如需统一请契约修订。
