# T005 交付说明（P4 外部音频导入）

## 范围与原则
- 只改 `audio/`、`ui/`、`tests/audio/`、`tests/ui/`；未改 `common/` 契约、未碰其他模块。
- 保留此前 audio/ 工作点（binding.py / duration.py / manifest.py / cli.py 雏形）不回退、不重写无关逻辑，按契约 v2 逐项复核后修正偏差。
- 本机无 ffmpeg/ffprobe；未自动安装、未下载、未用 skip 冒充通过。

## 按契约 v2 修正的偏差
1. 新增 `python -m audio.cli status`（契约 §1 要求；此前缺失，S01 E000188 也指出该缺口）。
2. 退出码/错误码对齐 §3/§7（原实现为 2/3/4，不符合）：
   - 数量不符、重复 seg_id、同一音频绑多段、缺失、未知 seg、`--audio-dir` 多余未绑定 → 顶层 `AUDIO_COUNT_MISMATCH`，退出码 5；
   - 参数/产物/格式错误 → `INVALID_INPUT`/`ARTIFACT_INVALID`/`NOT_FOUND`/`UNSUPPORTED_FORMAT`，退出码 2；
   - mp3/m4a 无 ffprobe → `duration_status=duration_unverified`，退出码 5，不计通过；
   - `synth` → `NOT_IMPLEMENTED`，退出码 6（原为 3），不创建输出目录、不产假音频。
3. 失败载荷改为契约 §3 统一形状 `{"status":"failed","error":{code,message,detail}}`；逐条问题放 `error.detail.issues`（BINDING_MISSING、BINDING_DUPLICATE、BINDING_DUPLICATE_FILE、EXTRA_UNBOUND_AUDIO 等）。原自定义顶层码（AUDIO_VALIDATION_FAILED 等）已废止。
4. 产物：保留 `audio_manifest.json`（第 5 步消费入口，新增 contracts_version/counts/message/ordinal/ffprobe_available），并新增标准 `manifest.json`（kind=audio，schema_version=2，files={"audio_manifest":"audio_manifest.json"}）；全部 verified → status=ok，否则 unverified（§2/§8）。
5. 绑定校验补强：给 `--audio-dir` 时绑定文件必须在该目录内；目录内未绑定音频拒绝；零帧 wav 记 probe_failed；段顺序以 index.json 为准，items 按 ordinal 输出。
6. 保留附加 `verify` 子命令（只复探时长、不改绑定，可 --out 重新出产物），不是新增契约命令，已在 README 说明。
7. UI 第 4 步：页面保留“人工等待”，新增 ffprobe 路径输入与 mp3/m4a 提示；runner 展示模块返回的人工/未验证信息；exit 5 → awaiting_manual，仅全部 verified 才 done，与 T004 状态口径一致。
8. 新增 `audio/README.md`：用法、绑定规则、产物字段、退出码、UI 行为与本期未实现能力。

## 已知限制
- 本机无 ffprobe，mp3/m4a 的正向探测（有 ffprobe 时解析时长）无法实测；只实测了“缺失→duration_unverified/退出 5”。`probe_with_ffprobe` 的错误分支用不存在的可执行文件覆盖为 probe_failed。
- `common/constants.py` 的 `MODULES["audio"]["implemented"]` 仍为 false；common/ 不在 T005 scope，S01 E000188 已建议由 MGR 决定验收后更新的归属。
- `verify` 为附加子命令；契约 §1 只列 status|import|synth。若审查认为不应保留，可移除而不影响 import 契约。
- 标准 manifest.json 的 artifact_id 由 seg_id+音频文件名/大小/时长状态哈希（不读音频内容）生成，同名的同大小同状态文件替换不会改变 id。
- 不校验音频内容与文案语义是否对应，不做响度/噪声/音质评估。
- `--binding` 相对路径按进程 cwd 解析（UI 子进程 cwd 为项目根）；`--bindings` 相对路径按绑定文件目录解析。
