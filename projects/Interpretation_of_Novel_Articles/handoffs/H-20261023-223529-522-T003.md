### 1. 交付内容
- `segmentation/chapters.py`：消费并校验第 1 步 `chapters.json`（schema_version=1、counting.rule=non_whitespace_chars、章号严格递增、偏移在 book.txt 内、区间不重叠、char_count 不超过区间非空白字符数）。缺失或置信度 <0.5 报 `CHAPTER_PARSE_LOW_CONFIDENCE`（退出码 5）并提示先跑 `python -m source.cli parse`，不静默回退；结构非法报 `ARTIFACT_INVALID`（退出码 2）。
- `segmentation/segmenter.py`：chars 模式按当前段累计 `target-chars`，边界章 `r > 1/3` 计入本段；`r <= 1/3`（含恰好 1/3，用 Fraction 精确判定）归下一段；`--drop-partial` 才丢弃边界章并写入产物与警告。chapters 模式每段固定 N 章、末段不足保留。任何模式不切章、段间不重叠、每段至少一章（首章即边界时强制保留并记 `forced_first_chapter`）。
- `segmentation/artifacts.py`：从 variant `manifest.files` 定位 text/chapters（拒绝绝对路径与目录逃逸）；写 `<variant_dir>/segments/<run_id>/<seg_id>/{segment.txt,segment.json,manifest.json}` 与 run 级 `index.json`；`segment.txt` 为 book.txt 原文切片；段 id = 章节范围 + 参数哈希（模式、目标、drop_partial、计数口径、契约版本、输入摘要）；同参数重跑默认报错不覆盖，`--force` 才重建；文件原子替换。
- `segmentation/cli.py`：`status|segment`；支持 `--variant-dir` 或 `--work-id/--variant-id`（+`--library-dir`）；`--target-chars`/`--chapters` 二选一；另有 `--drop-partial`、`--output-dir`、`--force`；统一 JSON 输出与固定退出码。
- `segmentation/README.md`：口径、输出布局、错误表与测试说明。
- `tests/segmentation/`：fixtures 构造带 manifest 的最小 variant；14 项规划单测 + 15 项 CLI 端到端测试。
