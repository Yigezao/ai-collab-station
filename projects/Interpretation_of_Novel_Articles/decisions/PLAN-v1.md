# 小说解说生成：按安全默认交付模块化流水线与 UI

## 范围与依据

依据 REQ-0001、S01-S04 三轮讨论及用户要求按 Q1-Q5 安全默认推进的答复。本方案将用户后续“批准”理解为同意提交方案供审批，不视为对网页内容使用权、付费 API、安装 ffmpeg 或不侵权作出授权。方案经用户明确批准前，不建任务、不实施。

目标是在项目工作区交付按功能命名、可独立运行且可串联的小说解说工具，含来源导入、章节截取、文案接口、人工配音导入、视频合成与操作 UI；以产物契约和 manifest 贯穿各模块，CLI/pipeline 为核心，UI 负责配置与调用。

## 范围与硬边界

1. **来源模块**：支持本地 TXT/EPUB 导入及 Project Gutenberg 公版目录检索/下载；多书名空格输入仅用于 Gutenberg 检索。普通网页 URL 提取默认关闭且不宣称支持；不得抓取任意小说站、跟随站内链接、模拟登录/点击或绕过访问控制。Gutenberg 条目保留来源与许可元数据；一次性观察不外推为长期覆盖结论。
2. **对比与选择**：同一 work 的多个 URL/来源分别作为 variant，不合并正文；生成排序与质量信息，比较前要求用户确认 work 绑定，默认 inferred。TLS 校验开启且不可关闭；robots/访问拒绝结构化失败，不降级、不重试。
3. **截取模块**：按完整章节截取；边界落在章节 1/3 以内时默认顺延下一段、不丢字，并提供显式 `--drop-partial` 选择丢弃；输出记录章节范围、字符数和规则。
4. **文案模块**：本期仅 mock，不产生真实文案，不配置或调用付费服务；真实生成列为未交付。不得承诺不侵权。README、UI 第 3 步、script.md 末尾及验收统一写：“本工具只做文本改写与相似度检测。相似度低于阈值不代表不侵权；解说、演绎可能构成改编，使用他人作品前请自行取得授权。”验收仅针对可测相似度阈值。中文测试夹具双轨：保留许可/出处的 Gutenberg 公版裁剪片段与自造 30 章样例。
5. **配音模块**：不做 TTS；只支持外部音频导入、时长探测和 manifest。第 2→3→4 链路在第 4 步暂停等待用户使用剪辑软件配音并导入；M 段文案须与 M 个音频按 `seg_id` 显式一对一绑定，数量不符、多余或未绑定即失败/需处理，不按文件名或位置兜底。`voiceover synth` 明确未实现并非零退出，不造假音频。
6. **视频模块**：ffmpeg/ffprobe 由用户自行安装，不打包、不自动下载、不静默回退。wav 可用标准库检测时长；mp3/m4a 缺少 ffprobe 时标 `duration_unverified` 且不计通过，P4/P5 整体验收不得 pass。支持视频素材与图片视频、明确的截取选择、图片数配置及按音频时长均分。执行前 preflight 检查依赖；时长截取需用户选择。
7. **UI**：五步工作流可单步运行、查看输入输出及状态，也支持步骤串联；第 4 步呈现人工等待与导入/绑定状态；失败和未实现状态显式显示。UI 不绕过模块契约。
8. **预算与运行**：当前仅 mock，不产生模型调用费用。若未来另案获批接入 HTTP 后端，必须显式配置并以 run 持久化 `logical_calls`、`request_attempts` 双上限，先预留后调用、重试计入 attempts、按 usage 对账；金额仅在用户给出单价时估算，不承诺金额上限。

## 步骤、owner、依赖及交付

| 阶段 | Owner / Reviewer | 依赖与交付 | 验收 |
|---|---|---|---|
| P0 契约、工程骨架与来源边界 | S01 / S04 | 方案批准后冻结目录、CLI、manifest、错误/状态、work/variant、来源许可字段和测试夹具约定；交付契约文档与可运行骨架。 | 各模块独立入口与公共契约一致；URL 功能默认关闭；来源信息可追溯。 |
| P1 来源导入、Gutenberg 检索、variant 选择 | S01 / S02 | 依赖 P0；交付本地导入、目录检索下载、候选对比/选择。 | 多书名逐项检索；同一 work 三 URL 形成三 variant 并正确排序而不拼接正文；work 绑定在比较前确认；TLS/拒绝行为符合边界。 |
| P2 章节解析与截取 | S02 / S04 | 依赖 P0；交付独立 CLI/API 和章节级产物。 | 按章节/字数截取、1/3 默认顺延与 `--drop-partial` 两种规则覆盖边界测试，内容不被静默丢弃。 |
| P3 文案 mock、相似度与 UI 工作流 | S03 / S02 | 依赖 P0/P2；交付 mock 标记、可测相似度结果、UI 单步/串联与版权提示。 | 不产生真实文案或网络调用；相似度阈值测试；版权提示逐处一致；中文两类 fixture 可复现。 |
| P4 人工配音导入与 manifest 绑定 | S03 / S04 | 依赖 P0/P3；交付外部音频导入、探测与 `seg_id` 绑定。 | 数量不符、重复/缺失/多余绑定拒绝；wav 时长正确；无 ffprobe 时 mp3/m4a 明确标记未验证且不计通过；TTS 不实现且非零退出。 |
| P5 视频合成、端到端集成与独立审查 | S04 / S01、S02 按模块复核 | 依赖 P0-P4；交付素材库接口、视频/图片视频生成、preflight、CLI/UI 集成及验收记录。 | 视频源与图片模式均有可复现测试；时长和截取选择符合契约；无 ffprobe 时受影响验收不判通过；完整链路保留每步产物及 manifest。 |

批准后由 MGR 按上述 owner/reviewer 建任务卡；owner 只改授权 scope 内路径，reviewer 独立复核并记录证据。任何新增普通网页抓取、真实生成后端/预算、自动 TTS、自动安装依赖或保证不侵权均超出本方案，需重新提交方案审批。

## 全局验收与交付

项目目录结构清晰；各模块可单独运行并产出契约化结果；至少一条 UI 串联流程可复现；测试与审查证据写入交接件；仅 `review_result=pass` 的任务可验收。交付包含源代码、README、示例配置/fixture、测试和已知限制说明。未交付项明确列为普通网页抓取、真实文案生成、TTS，以及无 ffprobe 环境下 mp3/m4a 时长和受其影响的端到端验收。

## 主要风险与控制

- 公版目录覆盖有限：以明确范围和来源记录控制预期。
- 章节识别受文本格式影响：用 fixture 和可见解析结果验证。
- 文案 mock 不满足真实生成需求：明确标注未交付。
- 外部工具缺失会阻塞部分音频/视频验收：不允许把 skip 计为通过。
- 模块并行依赖契约先冻结：P0 完成前其他模块不得自行改变字段契约。
