# 方案 v3：v3 UI 小白版设计方案：五步卡片、一屏一步、页面不出现术语（只设计，不落地）

# v3 UI 小白版设计方案

一句话：把页面改成五张大卡片，一屏只做一步；页面上不出现英文、文件名和术语，技术项全部收进“更多设置”。

## 1. 这一轮只交设计
- 本轮只产出这份设计方案，不改代码、不建实施任务。
- 批准后若要落地，再单独拆任务；落地时流水线、参数、校验都不动，只改看得见的一层。

## 2. 页面长什么样
- 顶部一行：“第 2/5 步”，旁边一句“只要稿子，做到第 3 步就能停”。
- 做过的步骤留一行“第 1 步 已完成 · 改这一步”；当前步骤整张展开；没到的步骤整张隐藏，不做折叠行。
- 每张卡片只有三样：一句“这一步做什么”、一个选或填的地方、一个大按钮。
- 做完不自动跳；结果下面给“进入第 3 步”大按钮。

## 3. 五步

### 第 1 步 · 找来一本书
- 看到：三个大按钮：① 用我电脑里的文件 ② 网上找免费老书 ③ 用上次导入过的。
- 点：① 选文件（可多选）→ 列出文件名 → 点“导入”；② 输入书名 → 点“搜一下” → 结果每行一个“下载这本”。
- 搜不到（0 条）：给三个按钮“换繁体书名再搜 / 用作者名搜 / 用电脑里的文件”。
- 连不上网：直接说“连不上，先用电脑里的文件”。
- 同一个文件又导入一次：问“这本已经导入过，直接用上次的？”。
- 拿到：一句“已准备好：《书名》”，一个按钮“对，就是这本”，然后是“进入第 2 步”。

### 第 2 步 · 把书切成小段
- 看到：《书名》，一个填空“每段大约多少字”，下面实时一句“大概 3 分半一段”。
- 点：“开始切分”。
- 拿到：分段列表（第 1 段《章节名》820 字……），底部“已切好 N 段” + “进入第 3 步”。
- 章节没认对：结果上方写“章节可能没认对，可以改成每 1000 字一段”，并给“重做这一步”。

### 第 3 步 · 写解说稿
- 看到：N 段列表带勾选框，两个选项：“先试写”“用 AI 写”。
- 点：
  - “先试写”：不联网、不花钱，文字是样例。
  - “用 AI 写”：弹出一个小框“把 AI 服务的钥匙粘在这里”，下面一句“只存在你这台电脑上”；不填就自动退回试写。
  - “写全部”或“只写勾选的”。
- 拿到：每段后面“已写好 · 查看”；失败的段变红，给“再试一次”。
- 长任务：页面写“正在写第 7/20 段”，并写“可以等，别关黑窗口”。
- 只想拿稿子：这里就可以停，页面写“稿子已写好，可以复制走”。

### 第 4 步 · 配上录音
- 看到：一句大提示“工具不会帮你配音，请先自己录好”；下面是 N 段列表。
- 点：选一个文件夹，点“自动配好”；工具按文件名顺序配。
- 拿到：“已配好 28 段，4 段没配上”，只补红色的段。
- 这个文件夹里只能放这 N 段音频，多一个都不行；多或少都会说清楚。

### 第 5 步 · 做成视频
- 看到：两个大按钮“用图片”“用视频画面”；一个“声音和画面不一样长怎么办”（4 个中文选项）；“竖屏 / 横屏”。
- 点：
  - 用图片：选一个图片文件夹，图片平均分给各段；只有一张封面图也行。
  - 用视频画面：选一个视频文件夹，按文件名顺序拼。
  - “开始做”。
- 拿到：“打开视频” + “打开所在文件夹”。
- 输出位置不用选：默认自动建“《书名》视频 10月24日 15点30”；重名自动加“(2)”，永远不报“文件夹已存在”。

## 4. 选项怎么说（勾了会怎样 / 不勾会怎样）

第 2 步
- 每段大约多少字（填 1000）：填大 = 段少、每段长；填小 = 段多、每段短；下面的“大概 3 分半一段”跟着变。
- 最后一小段不满一章，要不要单独算一段：勾了就多一段；不勾并到上一段，不会丢字。
- 替换上次的结果：勾了重做并替换；不勾碰到已有结果会停下来问。

第 3 步
- 谁来写：“先试写”（不联网、不花钱，文字是样例）/“用 AI 写”（会花钱，页面先写“大约 X 元”）。
- 重写已经写好的段：勾了把勾选的段再写一遍（再花一次钱）；不勾写过的跳过。
- 每次最多写多少段（填 20）：到数就停，已写的保留；填大 = 一次跑完但花钱多。

第 4 步
- 这个文件夹里只能放这 N 段音频：勾了多一个、少一个都会提醒；不勾可以随便选。
- 替换上次配好的音频：勾了重做并替换；不勾碰到已有结果会停下来问。

第 5 步
- 声音和画面不一样长怎么办：剪画面让画面跟着声音结束（推荐）/ 剪声音让声音跟着画面结束 / 补一段静音把短的补长 / 我自己定（填从第几秒到第几秒）。
- 画面方向：竖屏（手机、抖音）/ 横屏（电脑、B站）。
- 输出位置：不用选，自动建文件夹；重名自动加“(2)”，不会覆盖。

数字（分辨率、帧率）、工具位置、文件清单，一律不出现在主界面，收进“更多设置”。

## 5. 通用规则（小白常卡的点）
1. 关掉网页再打开：自动接上次的书和进度，顶部写“上次做到第 3 步”。
2. 黑色窗口被关：页面直接写“工具已关闭，双击 start_ui.bat 重新打开”，不留空白页。
3. 文件被移走或删了：写“上次用的《X》找不到了，请重新选一次”，带按钮回第 1 步。
4. 出错：只写“出了什么事 + 点这里怎么办”两行；原始内容收进“详情”。
5. 怕花钱或怕替换：动钱或替换前弹一句“这一步大约花 X 元 / 会替换上次结果，继续吗？”。
6. 按钮没亮：旁边灰字写“还差：选一个文件”，填齐才亮。
7. 说明太长：删掉整块常驻说明，字段旁一个问号点开一句话。

## 7. 边界
- 只改看得见的一层：页面文字、按钮、步骤顺序、错误提示。流水线模块、参数含义、校验规则都不动。
- 第 3 步默认“先试写” + 本机钥匙输入框属于行为变化：钥匙只存在本机，不写进做出来的东西，也不上传；落地时单独说明。
- 第 1 步多版本能力保留，但收成自动选 + “换一本”；不让小白看见“版本”“绑定”。
- 第 4 步自动配对依赖文件名顺序；配不上的只标红让用户补。
- 删除主界面的查重数字；“写完会标出太像原著的段”保留，数字收进更多设置。

## 8. 交付与验收
本轮交付：这份设计方案（文字稿），不含代码。
设计稿验收标准：
1. 五个步骤都有“看到 / 点 / 拿到”三句话，主界面无英文、无文件名、无术语。
2. 每个选项都写清“勾了会怎样、不勾会怎样”。
3. S02 列的 9 个卡点都有对应处理。
4. 未到步骤隐藏、不自动跳步、可回头改、可第 3 步停，四条规则写清。
5. 术语表可以直接当实施时的文案清单。

## 9. 风险与待确认
- 第 3 步钥匙输入框是新增行为；若不想改钥匙读取方式，可退回“只用先试写”，但 AI 写作对小白不可用。
- 第 4 步自动配对依赖文件名顺序，命名乱的文件夹仍需手动补。
- 第 5 步图片平均分配是设计口径，落地时要确认现有合成参数能否直接做到；做不到就改为“按段选图”。
- 搜索 0 条的三出口需要后端支持繁体书名和作者名检索，落地前要核实现有接口。
